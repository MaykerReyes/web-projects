Memory challenge

Repeat the light pattern

Watch the sequence carefully, then tap the lights in the same order. Each round adds one more step.

How to play

  1. Click Start Game and watch the colored pads flash in order.
  2. When it is your turn, tap the same pads in the same order.
  3. Each successful round adds one more step to remember.

Learning tip: Say the color names quietly (yellow, pink, green, blue) to lock the pattern in your memory.

Press Start to begin.
